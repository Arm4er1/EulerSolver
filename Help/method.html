Модифицированный метод Эйлера (Эйлер-Коши)

Постановка задачи

Решается задача Коши:

y' = f(x, y),   y(x0) = y0,   x ∈ [x0; xn]

Алгоритм метода

На каждом шаге интегрирования выполняются два вычисления:

Шаг 1 — Предиктор (прогноз):

y*[n+1] = y[n] + h · f(x[n], y[n])

Шаг 2 — Корректор (уточнение):

y[n+1] = y[n] + (h / 2) · [ f(x[n], y[n]) + f(x[n+1], y*[n+1]) ]

где:

  • h — шаг интегрирования
  • x[n+1] = x[n] + h
  • y*[n+1] — предварительное (предикторное) значение
  • y[n+1] — уточнённое значение

Характеристики метода

ХарактеристикаЗначение
Порядок точностиO(h²)
Количество вычислений f на шаг2
Тип методаЯвный предиктор-корректор
УстойчивостьУсловно устойчив

Контроль точности (правило Рунге)

При включённом контроле точности программа решает задачу дважды — с шагом h и с шагом h/2. Оценка погрешности:

eps ≈ |y(h) - y(h/2)| / 3

Если оценка превышает заданную точность eps, шаг уменьшается вдвое и вычисление повторяется.

Сравнение методов: обычный метод Эйлера имеет порядок точности O(h), модифицированный — O(h²). При уменьшении шага вдвое погрешность модифицированного метода уменьшается в 4 раза.
