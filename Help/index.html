Решение ОДУ модифицированным методом Эйлера

Курсовой проект по дисциплине «Разработка приложений в визуальных средах»
Выполнил: студент группы 10701324 Никитин Денис Алексеевич

Назначение программы

Программа предназначена для численного решения задачи Коши для обыкновенных дифференциальных уравнений (ОДУ) первого порядка вида y' = f(x, y) на заданном отрезке [x?; x?] с начальным условием y(x?) = y?.

Возможности программы

  • Решение ОДУ модифицированным методом Эйлера (Эйлер-Коши)
  • Ввод произвольного выражения f(x, y)
  • Автоматический подбор точного решения для типовых уравнений
  • Отображение результатов в таблице с погрешностями
  • Построение интерактивного 3D графика решения
  • Сравнение с обычным методом Эйлера
  • Сравнение с решением MATLAB (ode45)
  • Экспорт результатов в Excel, Word, CSV
  • Контроль точности по правилу Рунге

Системные требования

  • Windows 10 / 11
  • .NET 9.0
  • Microsoft Office (для экспорта в Excel и Word)
  • MATLAB (опционально, для сравнения с ode45)
