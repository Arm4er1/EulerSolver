Сравнение методов Эйлера

Обычный метод Эйлера

Формула одного шага:

yₙ₊₁ = yₙ + h · f(xₙ, yₙ)
  • Порядок точности: O(h)
  • Вычислений f на шаг: 1
  • Простейший явный метод

Модифицированный метод Эйлера

Предиктор + корректор:

ŷₙ₊₁ = yₙ + h · f(xₙ, yₙ)
yₙ₊₁ = yₙ + (h/2) · [f(xₙ,yₙ) + f(xₙ₊₁,ŷₙ₊₁)]
  • Порядок точности: O(h²)
  • Вычислений f на шаг: 2
  • Значительно точнее при том же шаге
