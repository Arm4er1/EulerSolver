Сравнение с MATLAB (ode45)

Как работает интеграция с MATLAB

  1. Нажмите кнопку Решить в MATLAB
  2. Программа автоматически генерирует скрипт (.m файл)
  3. MATLAB запускается и решает ОДУ методом ode45
  4. Результат передаётся обратно через временный CSV файл
  5. Открывается окно сравнения с графиком и таблицей

Метод ode45

MATLAB использует метод Рунге-Кутта 4-5 порядка с автоматическим контролем шага. Это значительно более точный метод чем метод Эйлера, что позволяет оценить погрешность нашего численного решения.

Сравнение методов

ХарактеристикаМод. ЭйлерMATLAB ode45
Порядок точностиO(h^2)O(h^5)
Контроль шагаФиксированныйАвтоматический
СкоростьОчень быстроМедленнее (запуск MATLAB)

Требования

MATLAB должен быть установлен на компьютере.
Поддерживаемые версии: R2022a и выше.
Внимание: первый запуск MATLAB может занять 15-30 секунд. Не закрывайте программу во время ожидания — статусная строка внизу покажет прогресс.

Синтаксис уравнений

Уравнение конвертируется в синтаксис MATLAB автоматически. Функция ln(x) преобразуется в log(x) (натуральный логарифм в MATLAB обозначается как log). Остальные функции совместимы напрямую.

Результат: после завершения вычислений открывается окно с таблицей сравнения и графиком — наш метод (синий) против MATLAB ode45 (оранжевый).
